# New Village

เกมฟาร์ม 2D ต้นแบบ สร้างด้วย TypeScript, Phaser และ Vite มีห้องเล่นร่วมกันแบบเรียลไทม์

มี 4 แผนที่ที่เชื่อมกัน: หมู่บ้าน บ้านและฟาร์ม ภายในบ้าน และตลาด ฉากแสดงเต็มหน้าต่าง และกล้องติดตามตัวละคร ภาพฉากถูกแบ่งเป็น Tilemap ขนาดช่อง 32 พิกเซล โดยมี Tilemap สิ่งกีดขวางแยกต่างหาก จุดโต้ตอบและประตูเปลี่ยนแผนที่กำหนดใน `src/maps.ts`

## เริ่มเล่น

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal (โดยปกติ `http://localhost:5173`)

## เล่นกับเพื่อน

สำหรับเล่นในเครื่องเดียวกัน ให้เปิดอีก Terminal แล้วรัน `npm start` หลังจาก `npm run build` เซิร์ฟเวอร์ห้องจะอยู่ที่พอร์ต 3000 กด **เล่นกับเพื่อน** ในเกม กรอกชื่อและรหัสห้องเดียวกัน แล้วเข้าห้อง ตัวละครของเพื่อนจะปรากฏเมื่ออยู่ในแผนที่เดียวกัน กดคัดลอกลิงก์เพื่อชวนเพื่อน

สำหรับเผยแพร่ให้เพื่อนเล่นผ่านอินเทอร์เน็ต ต้องใช้โฮสต์ที่รันเซิร์ฟเวอร์ Node.js และ WebSocket ได้ เช่น Render **Web Service**: นำโปรเจกต์นี้ขึ้น GitHub, สร้าง Web Service จาก repo, ตั้ง Build Command เป็น `npm ci && npm run build` และ Start Command เป็น `npm start` หรือใช้ `render.yaml` ที่มีให้ จากนั้นส่งลิงก์ `https://...onrender.com` ให้เพื่อนทุกคนเข้าเว็บเดียวกัน ไฟล์ `dist` บน Netlify Drop เพียงอย่างเดียวเล่นได้เฉพาะโหมดส่วนตัว เพราะ Netlify Drop ไม่ได้รันเซิร์ฟเวอร์ห้องของเกม

ผู้เล่นในห้องเห็นตำแหน่ง ชื่อ ตัวละคร และการเปลี่ยนแผนที่ของกันและกัน (สูงสุด 20 คนต่อห้อง) แต่แปลงผัก กระเป๋า เงิน และเควสต์ยังบันทึกแยกในเบราว์เซอร์แต่ละคน ห้องอยู่ในหน่วยความจำของเซิร์ฟเวอร์; เมื่อเซิร์ฟเวอร์รีสตาร์ตให้เข้าห้องใหม่

## ปุ่มควบคุม

- WASD หรือปุ่มลูกศร: เดิน
- เดินเข้าประตูหรือทางออกของแผนที่เพื่อเปลี่ยนฉากอัตโนมัติ
- 1–9 และ 0: เลือก Hotbar ช่อง 1–10 หรือคลิกช่องโดยตรง
- E, Space หรือคลิกในฉาก: ใช้ของที่เลือกกับแปลงหรือวัตถุใกล้ตัว และโต้ตอบกับ NPC
- ในร้านค้า กด 1 เพื่อซื้อเมล็ด และ 2 เพื่อขาย Radish; กด Esc เพื่อปิด
- ปุ่ม Player A / Player B มุมขวาบน: เปลี่ยนตัวละครที่เล่น

เริ่มในหมู่บ้าน เดินลงทางใต้ไปฟาร์ม ใช้จอบช่อง 1 ขุดแปลง เมล็ดช่อง 6 ปลูก บัวรดน้ำช่อง 2 รด รอ 60 วินาที แล้วใช้เคียวช่อง 5 เก็บเกี่ยว กลับไปขายกับ Shopkeeper ในหมู่บ้าน ขวานช่อง 3 ตัดต้นไม้ อีเต้อช่อง 4 ทุบหิน และเคียวตัดหญ้าเพื่อเก็บไม้ หิน และเส้นใย น้ำในบัวมี 10 หน่วย เติมได้ที่บ่อในฟาร์ม ช่อง 8–10 ใส่วัตถุดิบที่ลากจากกระเป๋าได้

เดินออกทางฝั่งตะวันตกของหมู่บ้านเพื่อเข้าตลาดโดยไม่ต้องกดปุ่ม ซื้อเมล็ด Radish (8 Coins), แครอท (10 Coins) และมะเขือเทศ (12 Coins) จากแผงเมล็ดพันธุ์ เมล็ดใหม่จะอยู่ในกระเป๋าและใส่ Hotbar ช่อง 8–10 อัตโนมัติหากมีช่องว่าง หากไม่ขึ้นให้ลากเมล็ดจากกระเป๋ามาใส่เอง ใช้จอบขุดแปลง เลือกเมล็ดแล้วปลูก รดน้ำ และเก็บด้วยเคียว แครอทขายที่ตลาดได้ 18 Coins และมะเขือเทศ 22 Coins

หนึ่งวันในต้นแบบใช้ 2 นาทีจริง ฝนตกทุกวันที่ 5 และรดแปลงที่เพิ่งปลูกให้อัตโนมัติ แปลงที่ปลูกแล้วไม่ได้รด 3 วันจะเหี่ยว ต้องใช้จอบขุดใหม่ เดินเข้าประตูบ้านในฟาร์มเพื่อเข้าภายในบ้าน เตียงช่วยฟื้น Energy หลังพัก 3 วินาที Cook สอนสูตรซุป Radish แล้วใช้ Radish เพื่อฟื้น Energy 15 ส่วน Village Guide รับ Radish 1 ชิ้นเพื่อให้รางวัล 20 Coins เกมบันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์นี้

Player A และ Player B มีสไปรต์โปร่งใสพร้อมท่ายืน เดิน 4 ทิศ รดน้ำ และเก็บเกี่ยว Shopkeeper, Cook และ Village Guide เป็นสไปรต์ NPC ในแผนที่

ทางไปป่าและริมน้ำแสดงเป็นจุดเชื่อมสำหรับอัปเดตถัดไป ระบบเก็บของและคราฟต์ยังไม่รวมใน MVP นี้
