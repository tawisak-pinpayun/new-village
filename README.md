# New Village

เกมฟาร์ม 2D ต้นแบบ สร้างด้วย TypeScript, Phaser และ Vite มี 3 เซิร์ฟเวอร์ให้เล่นร่วมกันแบบเรียลไทม์

มีหมู่บ้าน ฟาร์ม บ้าน ตลาด ริมน้ำ และเหมือง 3 ชั้นเชื่อมกัน ฉากแสดงเต็มหน้าต่างโดยใช้ภาพฉากหนึ่งภาพต่อแผนที่เพื่อลดอาการกระตุก และมีกล้องติดตามตัวละคร สิ่งกีดขวางอยู่ใน Collision Tilemap ขนาดช่อง 32 พิกเซล จุดโต้ตอบและประตูเปลี่ยนแผนที่กำหนดใน `src/maps.ts`

## เริ่มเล่น

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงใน Terminal (โดยปกติ `http://localhost:5173`)

## เล่นกับเพื่อน

สำหรับเล่นในเครื่องเดียวกัน ให้เปิดอีก Terminal แล้วรัน `npm start` หลังจาก `npm run build` เซิร์ฟเวอร์เกมจะอยู่ที่พอร์ต 3000 กด **เล่นกับเพื่อน** ในเกม กรอกชื่อและเข้า Server 1, 2 หรือ 3 ผู้เล่นในเซิร์ฟเวอร์เดียวกันจะเห็นกันเมื่ออยู่ในแผนที่เดียวกัน หากต้องการปาร์ตี้ให้สร้างรหัส 6 ตัวหรือกรอกรหัสของเพื่อน

สำหรับเผยแพร่ให้เพื่อนเล่นผ่านอินเทอร์เน็ต ต้องใช้โฮสต์ที่รันเซิร์ฟเวอร์ Node.js และ WebSocket ได้ เช่น Render **Web Service**: นำโปรเจกต์นี้ขึ้น GitHub, สร้าง Web Service จาก repo, ตั้ง Build Command เป็น `npm ci && npm run build` และ Start Command เป็น `npm start` หรือใช้ `render.yaml` ที่มีให้ จากนั้นส่งลิงก์ `https://...onrender.com` ให้เพื่อนทุกคนเข้าเว็บเดียวกัน ไฟล์ `dist` บน Netlify Drop เพียงอย่างเดียวเล่นได้เฉพาะโหมดส่วนตัว เพราะ Netlify Drop ไม่ได้รันเซิร์ฟเวอร์ห้องของเกม

ผู้เล่นในเซิร์ฟเวอร์เดียวกันเห็นตำแหน่ง ชื่อ ตัวละคร ชุด ไม้กวาด และการเปลี่ยนแผนที่ของกันและกัน แชทโลกแยกตามเซิร์ฟเวอร์และใช้ได้แม้ยังไม่เข้าเกม ข้อความแชท 40 รายการล่าสุดเก็บในหน่วยความจำเซิร์ฟเวอร์ เมื่อเซิร์ฟเวอร์รีสตาร์ตให้เข้าเซิร์ฟเวอร์ใหม่

## ปุ่มควบคุม

- WASD หรือปุ่มลูกศร: เดิน
- เดินเข้าประตูหรือทางออกของแผนที่เพื่อเปลี่ยนฉากอัตโนมัติ
- 1–9 และ 0: เลือก Hotbar ช่อง 1–10 หรือคลิกช่องโดยตรง
- E, Space หรือคลิกในฉาก: ใช้ของที่เลือกกับแปลง วัตถุหรือมอนสเตอร์ใกล้ตัว และโต้ตอบกับ NPC
- ในร้านค้า กด 1 เพื่อซื้อเมล็ด และ 2 เพื่อขาย Radish; กด Esc เพื่อปิด
- ปุ่ม Player A–H มุมขวาบน: เปลี่ยนตัวละครที่เล่น

เริ่มในหมู่บ้าน เดินลงทางใต้ไปฟาร์ม ใช้จอบช่อง 1 ขุดแปลง เมล็ดช่อง 6 ปลูก บัวรดน้ำช่อง 2 รด รอ 60 วินาที แล้วใช้เคียวช่อง 5 เก็บเกี่ยว กลับไปขายกับ Shopkeeper ในหมู่บ้าน ขวานช่อง 3 ตัดต้นไม้ อีเต้อช่อง 4 ทุบหิน และเคียวตัดหญ้าเพื่อเก็บไม้ หิน และเส้นใย น้ำในบัวมี 10 หน่วย เติมได้ที่บ่อในฟาร์ม ช่อง 8–10 ใส่วัตถุดิบที่ลากจากกระเป๋าได้

เดินออกทางฝั่งตะวันตกของหมู่บ้านเพื่อเข้าตลาดโดยไม่ต้องกดปุ่ม ซื้อเมล็ด Radish (8 Coins), แครอท (10 Coins) และมะเขือเทศ (12 Coins) จากแผงเมล็ดพันธุ์ เมล็ดใหม่จะอยู่ในกระเป๋าและใส่ Hotbar ช่อง 8–10 อัตโนมัติหากมีช่องว่าง หากไม่ขึ้นให้ลากเมล็ดจากกระเป๋ามาใส่เอง ใช้จอบขุดแปลง เลือกเมล็ดแล้วปลูก รดน้ำ และเก็บด้วยเคียว แครอทขายที่ตลาดได้ 18 Coins และมะเขือเทศ 22 Coins

หนึ่งวันในเกมใช้ 24 นาทีจริง เริ่มเวลา 06:00 และมีวงจรกลางวัน กลางคืน พร้อมแสงฉากที่ค่อย ๆ เปลี่ยน ฤดูใบไม้ผลิ ร้อน ใบไม้ร่วง และหนาว หมุนเวียนทุก 7 วันในเกม (เวลาและฤดูกาลของผู้เล่นในเซิร์ฟเวอร์เดียวกันอ้างอิงเซิร์ฟเวอร์ร่วมกัน) ฝนตกทุกวันที่ 5 และรดแปลงที่เพิ่งปลูกให้อัตโนมัติ แปลงที่ปลูกแล้วไม่ได้รด 3 วันจะเหี่ยว ต้องใช้จอบขุดใหม่ เดินเข้าประตูบ้านในฟาร์มเพื่อเข้าภายในบ้าน เตียงช่วยฟื้น HP มานา และ Energy หลังพัก 3 วินาที Cook สอนสูตรสตูว์จาก Radish กับเนื้อ และ Village Guide รับ Radish 1 ชิ้นเพื่อให้รางวัล 20 Coins เกมบันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์นี้

Player A–H มีสไปรต์โปร่งใสพร้อมท่ายืน เดิน 4 ทิศ รดน้ำ และเก็บเกี่ยว เปลี่ยนตัวละครได้ในหน้าแต่งตัวหรือปุ่มบนแถบด้านบน ชุดใหม่ได้แก่ชุดนักสำรวจ ชุดจอมเวทดวงดาว และชุดราชสำนักหรู Shopkeeper, Cook และ Village Guide เป็นสไปรต์ NPC ในแผนที่

ทางไปริมน้ำอยู่ฝั่งตะวันออกของหมู่บ้าน เดินเข้าถ้ำด้านตะวันออกเฉียงเหนือเพื่อเข้าเหมืองชั้น 1 แล้วเดินไปบันไดในเหมืองเพื่อลงชั้น 2 และ 3 ตลาดขายดาบ ธนู และข้าวกล่อง มีแผงเสื้อผ้าให้ซื้อชุดและสวมใส่ กับร้านเวทมนตร์ขายคทา ยามานา และไม้กวาดขี่ได้ ลากอุปกรณ์ไป Hotbar ช่อง 8–10 แล้วกด E เพื่อใช้ คทาใช้มานา 8 หน่วยต่อครั้ง ไม้กวาดเพิ่มความเร็ว อีเต้อช่อง 4 ใช้ขุดแร่ แร่แต่ละก้อนมีโอกาสดรอปจันทราศิลา 7%, 16% และ 30% ตามชั้น และโกเลมชั้น 3 ดรอปจันทราศิลาแน่นอน จันทราศิลาขายที่ตลาดได้หรือใช้กับเหล็ก 2 ชิ้นที่เตาหลอมชั้น 1 เพื่อทำดาบจันทรา มอนสเตอร์เกิดแบบสุ่มตามรอบเวลา เมื่อ HP หมดจะกลับไปฟื้นที่หมู่บ้าน ทางไปป่ายังรออัปเดต
